
# Apache Cordova

Mobile APK creator with HTML, JS, CSS.

## Useful Commands

```bash

$ cordova create .

$ cordova platform add browser | android 

$ cordova cordova build android

# Servers the root project folder for browser access
$ npx http-server www/ -p 8000

```
